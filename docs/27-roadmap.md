# خارطة الطريق

الفكرة ٢٣٩. **صفحة واحدة تقول ما تحقّق، وما لن يُبنى ولماذا، وما هو مفتوح
لمن يريد المساهمة.**

المصدر الكامل `docs/06-execution-plan.md`؛ هذه خلاصته لمن يقيّم المشروع من
الخارج.

## ما **لن** يُبنى، وسببه

**هذا القسم هو الأهمّ في الصفحة.** خارطة طريق تعدّد ما سيأتي فقط تخفي
نصف المعلومة.

| البند | لماذا لا |
|---|---|
| **المرحلة ١١ — تحسين الأداء** | ◐ **٤ من ١٠ مغلقة بقياس أُعيد عند السقف**: القياس الأصلي كان عند ٢٠ ألف رابط — ١٫٧٪ ممّا تتّسع له الخطة المجانية. إعادته عند ١٫٢ مليون رابط (١٫٠٠ غيغابايت) كشفت `/links/stats` عند ٩٧٢ ملّي ثانية، فشُحن ٢٧٣ و٢٧٦، وأُغلق ٢٧٥ و٢٧٧. الستّة الباقية **تبقى مؤجَّلة بلا دليل** — `docs/37-phase11-measurements.md` |
| **ترقيم بمؤشّر** | مرفوض **بقياس**: ١٣٧× أسرع نظرياً، أي ١٧ ملّي ثانية فعلياً |
| **مؤشّر «متصل الآن»** | يحتاج اتصالاً دائماً = عملية خلفية دائمة = القيد غير القابل للتفاوض |
| **شريط تقدّم للتصنيف** | الطلب رحلة واحدة؛ شريط محدّد فوقه يُوهم بمعرفة لا يملكها العميل |
| **استعادة نسخة احتياطية من اللوحة** | ملف يستبدل بيانات حيّة بلا تراجع. يحتاج تصميماً أمنياً لا زرّاً |
| **مزوّد LLM ثانٍ** | لا يوجد ثانٍ ضمن طبقة مجانية **دائمة** |
| **Docker، Oracle Cloud، أيّ خطة مدفوعة** | قيود صريحة لصاحب المشروع |

القائمة الكاملة بأسبابها في `docs/06-rejected.md`.

## مفتوح ويحتاج شرطاً خارجياً

ليس مرفوضاً — موقوف على شيء غير موجود بعد. **من يستطيع توفير الشرط يفتح
البند:**

| البند | الشرط الناقص |
|---|---|
| استخراج نصّ الملفات (١–٤) | الجامع **لا ينزّل الوسائط أصلاً**؛ يحتاج قدرة تنزيل، لا مكتبة |
| استيراد أرشيف WhatsApp (٥) | عيّنات تصدير حقيقية |
| تقييم دقّة التصنيف وضبط العتبات (١٨، ١٩، ٢٦–٢٩) | مجموعة بيانات مُصنَّفة يدوياً. **آليّة إنتاجها شُحنت** (تسجيل كل تصحيح بشري) — الترتيب مقصود |
| صلاحيات متعدّدة المستخدمين (٦ب) | تصميم مكتوب. XL، وليس سطر كود |
| «أعد الفحص الآن» (٤٧) | تصميم أمني مكتوب: سطح SSRF جديد |
| استثناء نطاقات من الفحص (٤٩) | قرار تصميم متعدّد المستأجرين |

## أنسب ما يُساهَم به

مرتّبة بالأثر لا بالسهولة:

1. **عيّنة تصدير WhatsApp حقيقية** — تفتح بنداً موقوفاً منذ المرحلة ٢.
2. **تصنيف يدوي لمجموعة روابط** — يفتح ستّة بنود دفعة واحدة.
3. **قاعدة تصنيف لنطاق يُصنَّف خطأً باستمرار** — أصغر مساهمة ممكنة وأوضحها
   أثراً. والمنصّة **تخبرك بأيّ نطاق**: بعد ثلاثة تصحيحات على النطاق نفسه
   يصلك تنبيه.
4. **ترجمة الواجهة إلى الإنجليزية (٢٥٦)** — البنية جاهزة، والنصوص عربية.
5. **تحسين الإتاحة** بقارئ شاشة حقيقي — الاختبارات تفحص الوسوم لا التجربة.

`CONTRIBUTING.md` يشرح الدورة. **اقرأ `docs/06-rejected.md` قبل اقتراح
فكرة كبيرة** — وُجد ليمنع إعادة تقييم ما قُيِّم.

## ما لا تَعِد به هذه الصفحة

يعمل عليه شخص واحد، وموعدٌ يُكتب هنا سيكون تخميناً معروضاً كالتزام.

ولا تحاول هذه الصفحة تحسينه بالصياغة.
