# قاموس المصطلحات

الفكرة ٢٢٧. كل مصطلح تقني يمرّ في وثائق هذا المشروع، بلغة يفهمها من لم
يكتب الشيفرة. **بالترتيب الذي يصادفه القارئ لا بالترتيب الأبجدي**، لأنّ من
يبحث عن معنى «العلامة المائية» يبحث عنه وهو يقرأ عن الجمع.

---

## مفاهيم المنصّة

| المصطلح | بالعربية المبسّطة |
|---|---|
| **مساحة عمل** (workspace) | الحاوية التي تملك كل شيء: روابطك وقنواتك وحساباتك. كل صفّ في القاعدة يحمل رقمها، وكل استعلام يُصفّى بها. هي حدّ العزل بين المستخدمين |
| **جلسة** (session) | إثبات أنّك سجّلت الدخول، محفوظ في كعكة المتصفّح ومقابله صفّ في القاعدة. إلغاء الصفّ يُنهي الجلسة فوراً — لهذا هي «قابلة للإبطال» |
| **مفتاح API** | بديل الجلسة للسكربتات. يبدأ بـ`lipk_`، ويُعرض مرّة واحدة، ولا يستطيع لمس الإعدادات الأمنية |
| **قناة** | مصدر روابط. عادةً قناة تلغرام، وأحياناً «سلّة» اصطناعية للّصق اليدوي أو للاستيراد |
| **حساب جمع** | حساب تلغرام حقيقي تُستخدَم جلسته لقراءة القنوات. مختلف عن البوت تماماً |
| **بوت** | حساب تلغرام آليّ يستقبل أوامرك ويرسل تنبيهاتك. لا يقرأ القنوات |

## الجمع والتصنيف

| المصطلح | بالعربية المبسّطة |
|---|---|
| **العلامة المائية** (watermark) | رقم آخر رسالة قُرئت في قناة. التشغيلة التالية تبدأ بعدها، فلا تُقرأ رسالة مرّتين ولا تُتخطّى واحدة |
| **منع التكرار** (dedup) | رفض تخزين الرابط نفسه مرّتين في القناة نفسها. المفتاح هو (القناة + بصمة الرابط) |
| **بصمة الرابط** (`url_hash`) | تحويل نصّ الرابط إلى سلسلة بطول ثابت. تُستخدَم مفتاحاً للفهرسة لأنّ نصّ الرابط قد يطول بما يتجاوز حدّ فهرس Postgres |
| **SAVEPOINT** | نقطة تراجع **داخل** المعاملة. تسمح بإلغاء رابط مكرّر واحد دون إلغاء العشرة التي جُمعت معه |
| **القاعدة التي أطلقت التصنيف** (`matched_rule`) | ما جعل الرابط يقع في تصنيفه، مثل `extension:pdf`. تُخزَّن لأنّ تصنيفاً خاطئاً بلا سبب معروف لا يُصلَح |
| **الطبقة الاختيارية** | نموذج لغوي مجاني يُستشار **فقط** حين تكون ثقة القواعد منخفضة. غيابه لا يعطّل شيئاً |

## الحيوية والاستبقاء

| المصطلح | بالعربية المبسّطة |
|---|---|
| **الحيوية** (vitality) | هل الرابط ما يزال يعمل. تُفحَص دورياً بطلب خفيف |
| **«تأكّد موته»** | الفحص وجده ميتاً. **لا يعني أنّه مات اليوم** — قد يكون مات قبل شهور والفحص التقطه الآن. الفرق مقصود في كل نصّ |
| **الإخفاقات المتتالية** | عدّاد يرتفع مع كل فحص فاشل ويُصفَّر عند أوّل نجاح. يقرّر متى يُعتبر الرابط ميتاً فعلاً، ومتى يُخفَّف تواتر فحصه |
| **الأرشفة** | إخفاء رابط من نتائج البحث الافتراضية دون حذفه |
| **التقليم** (prune) | حذف ما انتهت مدّة استبقائه فعلاً |

## الأمن

| المصطلح | بالعربية المبسّطة |
|---|---|
| **تجزئة** (hash) | تحويل لا رجعة فيه. كلمات المرور مُجزَّأة: لا أحد يستطيع استخراجها، حتى من يملك القاعدة |
| **تشفير الحقل** | تشفير **قابل للفكّ**، لِما يجب استعادته كما هو — جلسة تلغرام مثلاً. المفتاح هو `FIELD_ENCRYPTION_KEY`، وفقدانه يعني فقدان تلك الحقول نهائياً |
| **بيانات اعتماد حاملة** (bearer) | أيّ شيء يكفي حَمْلُه للتصرّف بصفتك: مفتاح API، رمز البوت، جلسة تلغرام. لا يُسجَّل ولا يُعاد في أيّ استجابة |
| **TOTP** | رمز ستّة أرقام يتغيّر كل ٣٠ ثانية في تطبيق على هاتفك. يُرفَض الرمز إن استُخدم مرّة سابقاً |
| **رموز الاسترداد** | عشرة رموز تُعرض مرّة واحدة، كلٌّ يُستخدَم مرّة، للدخول إن فُقد الهاتف |
| **CSP** | ترويسة تقول للمتصفّح: نفّذ فقط الشيفرة الآتية من هذا الموقع. تجعل ثغرة حَقْن نصّ غير قابلة للاستغلال |
| **SSRF** | خداع الخادم ليطلب عنواناً داخلياً بالنيابة عن المهاجم. هو الخطر الوحيد في الـwebhook الخارجي، ولهذا تُرفض العناوين الداخلية ولا يُتَّبع أيّ تحويل |
| **عزل المستأجرين** | ألّا ترى مساحة عمل بيانات أخرى. يُختبَر بمسح آليّ على **كل** نقطة تأخذ معرّفاً |
| **٤٠٤ لا ٤٠٣** | معرّف من مساحة أخرى يُقال عنه «غير موجود» لا «ممنوع». الثاني يؤكّد وجوده، وهو ما يبحث عنه من يجرّب المعرّفات بالتسلسل |

## التشغيل

| المصطلح | بالعربية المبسّطة |
|---|---|
| **الهجرة** (migration) | خطوة مرقّمة تُعدّل بنية القاعدة. تُطبَّق بالترتيب عند كل إقلاع |
| **`alembic check`** | يسأل: هل نموذج الشيفرة يطابق بنية القاعدة؟ اختلافهما يعني هجرة منسيّة |
| **تشغيلة مجدولة** | مهمّة تعمل بموعد في GitHub Actions. بديل «العملية الخلفية الدائمة» التي لا توجد لها خطة مجانية |
| **البرود** (cold start) | التأخّر الأوّل بعد نوم الخدمة. نحو دقيقة |
| **«منذ الإقلاع»** | كل عدّاد يبدأ من الصفر عند استيقاظ الخدمة. تقديمه كـ«إجمالي» رقمٌ يعني شيئاً آخر |
| **لوحة الحالة** | آخر نتيجة لكل تشغيلة مجدولة. التشغيلات **تُبلِّغها** بمفتاح API، ولا تقرأ الخدمة واجهة GitHub |
| **البوّابة** (في التنبيهات) | الفحص الذي يقرّر إن كان نوع التنبيه مفعَّلاً. **كل** تنبيه يمرّ به، والـwebhook الخارجي يُرسَل من بعده لا قبله |
