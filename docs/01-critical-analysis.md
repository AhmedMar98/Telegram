## 1.1 تحليل السياق

**الدور:** BA

| البند | التوصيف |
|---|---|
| الجمهور المستهدف المعلَن | مشغّل يبحث في روابط مجمّعة من قنوات مراقَبة، ومستأجر يشتري وصولاً إلى المنصّة كخدمة |
| نموذج القيمة المعلَن | تحويل تدفق روابط غير منظّم إلى فهرس مصنَّف ومُتحقَّق من حيويته وقابل للبحث الدلالي |
| مصدر التمايز المدّعى | التصنيف متعدد الطبقات الذي يقلّل كلفة النماذج، والبحث الهجين الذي يدمج النص بالدلالة |
| الافتراض الضمني الأول | أن جمع البيانات من المنصّة عبر حساب مستخدم مشروع وقابل للاستمرار — **لم يُختبر** |
| الافتراض الضمني الثاني | أن الروابط المجمّعة لا تحمل بيانات شخصية — **مخالف للواقع**: روابط المراسلة المباشرة تتضمّن أرقام هواتف، وسياق الرسالة يُخزَّن نصاً |
| الافتراض الضمني الثالث | أن التصنيف متعدد الطبقات دقيق بما يكفي للاعتماد عليه — **غير مقيس**، لا توجد مجموعة تقييم مرجعية |
| الافتراض الضمني الرابع | أن البحث الهجين يعمل بشقّيه — **مخالف للواقع**: الشق الدلالي غير عامل |
| الافتراض الضمني الخامس | أن الوصول إلى اللوحة والواجهة محمي — **مخالف للواقع**: لا مصادقة منفَّذة |
| الافتراض الضمني السادس | أن حدود الخطط تحمي من الاستهلاك المفرط — **مخالف للواقع**: غير مفروضة في مسار الطلب |

## 1.2 سلّم التقييم

**الدور:** RSK — يُعرَّف السلّم قبل أي تصنيف، ولا يُصنَّف خطر بالانطباع.

### سلّم الأثر

| الدرجة | التعريف الملزم |
|---|---|
| 5 | توقّف الخدمة، أو مسؤولية قانونية، أو كشف بيانات، أو انهيار الثقة بالمخرج |
| 4 | فقد ميزة محورية، أو خسارة مالية مباشرة، أو خرق عزل بين مستأجرين |
| 3 | تدهور ملموس في الأداء أو الدقة أو قابلية التشغيل دون توقّف |
| 2 | إزعاج تشغيلي أو ارتباك في التوثيق دون أثر وظيفي |
| 1 | أثر تجميلي |

### سلّم الاحتمالية

| الدرجة | التعريف الملزم |
|---|---|
| 5 | متحقق فعلاً في الحالة الراهنة، لا احتمال |
| 4 | يتحقق حتماً عند أول تشغيل إنتاجي |
| 3 | يتحقق عند شرط تشغيلي معتاد الحدوث |
| 2 | يتحقق عند شرط نادر |
| 1 | يتطلب تضافر ظروف غير معتادة |

**الدرجة = الأثر × الاحتمالية.** النطاق 1–25. عتبة الخطورة الحرجة: 20 فأعلى.

## 1.4 مخاطر الامتثال والخصوصية

**الدور:** CMP — بند إلزامي لا يُسقط.

| المحور | الواقع المرصود | الخطر المرتبط |
|---|---|---|
| مشروعية الجمع | الجمع يتم عبر حساب مستخدم مؤتمت، لا عبر واجهة روبوت معتمدة | R-05 |
| صنف البيانات المجمّعة | روابط المراسلة المباشرة تتضمّن أرقام هواتف؛ وسياق الرسالة نص حرّ قد يحمل معرّفات شخصية | R-02, R-06 |
| أساس المعالجة | لا أساس معالجة مثبت ولا إشعار ولا موافقة | R-02, R-06, R-14 |
| حقوق أصحاب البيانات | لا مسار للوصول ولا للتصحيح ولا للحذف بطلب | R-17 |
| الاحتفاظ والحذف | لا سياسة منفَّذة؛ البيانات تتراكم بلا انتهاء صلاحية | R-07 |
| إعادة النشر | روابط دعوة لمجموعات خاصة تصبح قابلة للاكتشاف عبر بحث يُباع | R-08 |
| النقل إلى أطراف ثالثة | نص الرابط وسياقه يُرسَلان إلى مزوّدي نماذج خارجيين للتصنيف | R-06 |
| العزل التعاقدي | البيع متعدد المستأجرين قائم بينما العزل غير مفروض تقنياً | R-03, R-14 |

**خلاصة الدور:** محور الامتثال هو أعلى تركيز للمخاطر الحرجة في هذا النظام، وليس محور الهندسة.
