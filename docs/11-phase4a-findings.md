# المرحلة ٤أ — اللوحة والإتاحة

المرحلة ٤ تحمل ٤٥ فكرة: اللوحة (١٢١–١٣٥)، بوت تيليجرام (١٣٦–١٥٠)، والتدويل
والإتاحة (٢٥٦–٢٧٠). هذه الدفعة تعالج اللوحة والإتاحة معاً لأنهما تلمسان
الملفين نفسيهما، كما نصّت خطة التنفيذ. البوت دفعة ٤ب.

---

## ١. عيبان حقيقيان كشفهما القياس

### ١.١ حدود الحقول تسقط في اختبار WCAG

القياس أولاً، لا الحكم بالنظر. حُسبت نسبة التباين لكل زوج نصّ/خلفية
مستخدَم فعلياً في الوضعين، بصيغة WCAG 2.1 (النصوع النسبي):

| الزوج | الوضع الفاتح | الوضع الداكن | الحدّ |
|---|---|---|---|
| نصّ الصفحة | ١٧٫٤٠ ✅ | ١٤٫٣٩ ✅ | ٤٫٥ |
| نصّ خافت | ٦٫٩٠ ✅ | ٧٫٣٤ ✅ | ٤٫٥ |
| الروابط | ٦٫٣٩ ✅ | ٧٫٥٧ ✅ | ٤٫٥ |
| **حدود الحقول** | **١٫٥٤ ❌** | **١٫٥٦ ❌** | **٣٫٠** |

النصوص كلها تمرّ بمريحة. لكن **حدّ الحقل** (البند ١٫٤٫١١ — تباين غير
النصّ) يسقط في الوضعين: حدود صناديق الإدخال والبطاقات كانت شبه معدومة
لمن لديه ضعف بصري.

الإصلاح ليس اختياراً ذوقياً: `#919191` هو **أفتح رمادي** يعبر ٣٫٠ مقابل
الصفحة والبطاقة معاً (٣٫١٥ و٣٫٠٢)، و`#636a74` نظيره في الوضع الداكن —
أي أقلّ تغيير بصري يسمح به المعيار.

الاختبار `tests/test_accessibility.py` يقرأ الألوان **من `base.html`
نفسه** لا من نسخة في الاختبار، فتغيير لاحق في الورقة يُكشف. وتحقّقنا أنه
حارس حقيقي بتشغيله على القيم القديمة: يسقط في الحالات الأربع.

### ١.٢ شريط «تراجع» المخفي كان قابلاً للتركيز بلوحة المفاتيح

اكتُشف بالتنقّل الفعلي بـTab في Chromium لا بقراءة الترميز. الترتيب كان:

```
الرئيسية → دخول → تسجيل → زر المظهر → [تراجع] ← زر داخل عنصر hidden
```

السبب: `<div id="undoBar" hidden style="display:flex">`. خاصية `display`
السطرية **تتفوّق** على قاعدة المتصفّح `[hidden] { display: none }`، فيبقى
العنصر في التخطيط وفي ترتيب التبويب وهو غير مرئي — يستطيع مستخدم لوحة
المفاتيح التركيز على زر لا يراه والضغط عليه.

الإصلاح: نُقل التخطيط إلى صنف CSS، وأُضيفت `[hidden] { display: none
!important; }` صراحةً حتى لا يعتمد الضمان على ترتيب القواعد. والاختبار
`test_hidden_panels_carry_no_inline_display` يمنع تكرارها في أي لوحة
مخفية أخرى.

بعد الإصلاح صار الترتيب مطابقاً للترتيب البصري تماماً.

## ٢. ما شُحن (١٩ فكرة)

| # | الفكرة | ملاحظة |
|---|---|---|
| ١٢١ | اختصارات لوحة مفاتيح | اثنان فقط: `/` للبحث و`Esc` للتراجع. لا اختصارات مخترَعة |
| ١٢٢ | نافذة تراجع ٥ ثوانٍ | لا شيء يُحذف من الخادم قبل انقضائها — تراجع حقيقي لا إعادة إدراج |
| ١٢٣ | عدّاد نتائج حيّ أثناء الكتابة | `page_size=1` بتأخير ٣٠٠ms |
| ١٢٥ | عرض مضغوط | ثلاث كثافات بزرّ واحد: قائمة / شبكي / مضغوط |
| ١٢٦ | تذكّر آخر الفلاتر | يُستشار فقط حين لا يحمل العنوان فلاتر |
| ١٢٧ | صفحة بداية سريعة | لمساحة عمل فارغة فقط، وتُخفى نهائياً بالنقر |
| ١٢٨ | «منذ متى لم يعمل الجمع» | من سجلّ التدقيق، لا عمود جديد |
| ١٢٩ | زر نسخ الرابط | مع إعلان للقارئ الصوتي |
| ١٣٠ | تلميح يشرح rules/llm/manual | مكتوب حيث تُعرض القيمة |
| ٢٥٧ | فحص التباين | §١٫١ — أصلح عيباً مقيساً |
| ٢٥٨ + ٢٦٥ | `aria-label` لكل زر أيقوني | ★ ⧉ 🗄 وأزرار الصفحات |
| ٢٥٩ | تكبير ١٥٠٪/٢٠٠٪ | مُقاس فعلياً في المتصفّح |
| ٢٦٠ + ٢٦٧ | تنقّل ولوحة مفاتيح وترتيب تبويب | §١٫٢ — أصلح عيباً |
| ٢٦١ | `aria-live` للحالات | `polite` للعدّاد، `alert` لنافذة التراجع |
| ٢٦٣ | تنسيق تاريخ محلي متسق | `toLocaleString("ar")` في كل موضع |
| ٢٦٦ | `prefers-reduced-motion` | |
| ٢٦٩ | اتجاه bidi للروابط اللاتينية | `direction: ltr; unicode-bidi: isolate` |
| ٢٧٠ | تكبير منطقة اللمس | `min-height/min-width: 2.25rem` (WCAG 2.5.8) |

**لماذا اختصاران فقط (١٢١):** صفحة مليئة باختصارات أحادية الحرف فخّ لمن
يكتب في حقل. `/` هو ما تستخدمه GitHub وGmail وSlack، و`Esc` يعني «تراجع
عمّا فعلته للتو» بالترتيب المتوقّع: يلغي حذفاً معلّقاً أولاً، ثم يفرغ
البحث.

**لماذا `alert` لا `polite` لنافذة التراجع (٢٦١):** العرض ينتهي بعد خمس
ثوانٍ. `polite` ينتظر فجوة في الكلام، فقد يصل الإعلان بعد ضياع الفرصة.

## ٣. فكرتان رُفض تنفيذهما بعد الفحص

**١٢٤ — شريط تقدّم أثناء «إضافة وتصنيف».** `POST /links` رحلة واحدة
ذهاباً وإياباً: الخادم يستقبل النصّ كاملاً ويردّ مرّة واحدة. شريط تقدّم
**محدّد** فوقه لا يمكن أن يعكس شيئاً حقيقياً — سيكون رسماً متحرّكاً
يُوهم بمعرفة لا يملكها العميل. البديل الصادق (حالة انشغال غير محدّدة)
موجود أصلاً في نصّ الزر. تنفيذها يتطلّب بثّ التقدّم (SSE أو ردّ متدفّق)،
وهو تغيير في شكل نقطة النهاية لا زخرفة، ولا مبرّر له اليوم.

**١٣٥ — مؤشر «متصل الآن» عبر WebSocket.** يصطدم بقيد غير قابل للتفاوض:
اتصال دائم يعني عملية خلفية دائمة، والخطة الحرة على Render تُوقف الخدمة
عند الخمول أصلاً. المؤشّر سيكون «غير متصل» معظم الوقت أو يبقي الخدمة
مستيقظة على حساب الحصّة. مرفوضة معمارياً لا لضيق الوقت.

## ٤. ما أُجّل

- **١٣١ (صفحة إعدادات موحّدة)** — إعادة هيكلة للوحة كاملة، لا بند في دفعة.
- **١٣٣ (حجم الاستيراد المتوقّع) و١٣٤ (سحب وإفلات ملف JSON)** — كلاهما
  يحتاج نقطة نهاية استيراد تستقبل ملفاً مرفوعاً، وهي غير موجودة. تُصمَّم
  معاً لا كل على حدة.
- **٢٥٦ (تبديل لغة الواجهة)** — يحتاج استخراج كل النصوص إلى ملفات ترجمة
  أولاً؛ عملية ميكانيكية واسعة تستحقّ دفعتها.
- **٢٦٢ (axe-core كبوابة CI)** — يضيف اعتماديّة Node إلى CI لم تكن موجودة.
  قرار CI لا قرار واجهة.
- **١٣٢ (رسالة فارغة أوضح)** — **منفَّذة سلفاً** في المرحلة ٣ب (اقتراح
  التصنيفات التي فيها روابط).
- **١٣٦–١٥٠ (البوت)** — دفعة ٤ب.

## ٥. قياس صادق: ٢ بكسل تجاوز أفقي عند ٢٠٠٪

عند تصغير النافذة إلى ٦٤٠px وتكبير الخطّ إلى ٣٢px (تكبير ٢٠٠٪):

```
document.scrollWidth - clientWidth = 2
العناصر المتجاوزة = []
```

أي أن **لا عنصر** يتجاوز عرض الصفحة؛ الفارق تقريب دون-بكسلي بين
`max-width` و`padding` على `body`. لا يُنتج شريط تمرير مرئياً ولا يكسر
تخطيطاً. مذكور هنا لأن قول «صفر» كان سيكون أدقّ ممّا يسمح به القياس.

## ٦. الأدلة

| ما جرى التحقّق منه | كيف |
|---|---|
| التباين | حساب صيغة WCAG على الألوان المقروءة من `base.html`، وتحقّق من أن الاختبار يسقط على القيم القديمة (٤ حالات) |
| صحة صيغة الحساب نفسها | أسود على أبيض = ٢١٫٠٠ بالضبط |
| ترتيب التبويب | Tab من رأس المستند في Chromium: نُقر إلى أن اختفى زر التراجع المخفي |
| `/` و`Esc` | `/` يركّز الحقل ولا يكتب فيه؛ `Esc` يفرغه |
| نافذة التراجع | التراجع → ٣ من ٣ (لا حذف)؛ انقضاء المهلة → ٢ من ٢ (حُذف) |
| الكثافات الثلاث | `grid-results` ← `card.compact` ← عادي، بالدوران |
| اتجاه bidi | `direction: ltr`، `unicode-bidi: isolate` محسوبتان على عنصر الرابط |
| بروز التركيز | `outlineColor` يُحلّ إلى `rgb(11, 87, 208)` |
| البداية السريعة | ظاهرة لمساحة فارغة، مخفية بعد وجود روابط |
| صحّة الجمع | ثلاثة اختبارات: لم يعمل قط / منذ ساعتين / منذ ٣ أيام، وعزل بين المستأجرين |
| لا يُخلَط سجلّ تدقيق آخر بالجمع | حذف رابط يكتب صفّ تدقيق ولا يُحسب تشغيلة جمع |
