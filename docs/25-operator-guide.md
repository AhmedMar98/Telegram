# دليل المشغّل

الفكرة ٢٣٥. **من يشغّل المنصّة ومن يستخدمها شخصان مختلفان، ولو كانا الشخص
نفسه — لأنّهما يقرآن في لحظتين مختلفتين.** المستخدم يقرأ ليحفظ رابطاً؛
المشغّل يقرأ لأنّ شيئاً يحتاج ضبطاً أو تعطّل.

**هذه الوثيقة فهرس لا نسخة.** التفاصيل تعيش حيث تُصان، وتكرارها هنا يضمن
نسختين تتباعدان. ما يضيفه هذا الملف هو **الترتيب**: ما يُفعَل أوّلاً، وما
يُتحقَّق منه، وأين يُنظَر عند العطل.

## ٢. الأسرار — قاعدتان لا تُخترقان

1. **لا يُكتب سرّ في هذا المستودع.** أبداً، ولا «مؤقّتاً».
2. **السرّ الذي ظهر في لقطة شاشة أو سجلّ هو سرّ مسرَّب.** يُبطَل ويُستبدَل،
   لا يُقيَّم احتمال أن يكون أحد رآه.

الجدول المركزي — مولَّداً من الشيفرة نفسها لا مكتوباً باليد —
في `docs/29-env-vars.md`. ومنه تحديداً عمود **«سرّ؟»**.

**تدوير `FIELD_ENCRYPTION_KEY`:** `scripts/rotate_encryption_key.py`، مع
ضبط `FIELD_ENCRYPTION_KEY_OLD` أثناء التدوير فقط.

## ٣. الجدولة — ما يعمل وحده

| التشغيلة | الملفّ | الدورية |
|---|---|---|
| الجمع | `.github/workflows/collector.yml` | كل ساعة |
| الحيوية | `.github/workflows/vitality.yml` | دورية |
| التقليم | `.github/workflows/prune.yml` | دورية |
| النسخ الاحتياطي | `.github/workflows/backup.yml` | أسبوعياً، الأحد ٠٣:٠٠ UTC |
| الملخّص الأسبوعي | `.github/workflows/weekly-digest.yml` | أسبوعياً، الأحد ٠٧:٠٠ UTC |
| التقرير الشهري | `.github/workflows/monthly-report.yml` | أوّل كل شهر |
| اختبار الدخان | `.github/workflows/smoke.yml` | كل ٦ ساعات |

**كلّها تُبلِّغ نتيجتها إلى `/status`** عبر `report-run.yml` بمفتاح API لا
يلمس المستودع. ولوحة فارغة تماماً تعني غالباً أنّ `APP_API_KEY` أو
`APP_BASE_URL` غير مضبوط — لا أنّ كل شيء توقّف.

## ٤. المراقبة — من يخبرك، وخلال كم

الجدول الكامل في `docs/19-runbook.md` §١. خلاصته:

- **مفعَّل افتراضاً:** فشل الجامع، اقتراب حدّ التخزين، دخول من جهاز جديد،
  نتيجة النسخ الاحتياطي، حصّة Groq.
- **مطفأ افتراضاً:** الملخّصات، محتوى البالغين، التصنيف المتضارب.

**رسالة النسخ الاحتياطي تصل عند النجاح أيضاً**، ليكون **غيابها** هو
الإشارة.

**مراقبة خارجية مجانية (UptimeRobot):** `docs/19-runbook.md` §٢ — واضبطها
على `/healthz` لا `/readyz`.

## ٦. الصيانة الدورية

| كل | ماذا |
|---|---|
| **أسبوعياً** | تأكّد أنّ رسالة النسخ الاحتياطي وصلت. غيابها ليس هدوءاً |
| **شهرياً** | اقرأ التقرير الشهري: الحجم، معدّل النموّ، الإسقاط إلى الحدّ |
| **دورياً** | **اختبر استعادة فعلية** — `docs/19-runbook.md` §٦. نسخة لم تُستعَد مرّة ليست نسخة احتياطية بل ملفّ |
| **عند كل سرّ جديد** | `python scripts/env_report.py`، ويفشل اختبار إن نُسي |
| **عند كل رفض فكرة** | حدّث `docs/06-rejected.md` |

## ٧. حدود يجب أن يعرفها المشغّل قبل أن تفاجئه

- **الخدمة تنام** بعد ١٥ دقيقة خمول، وأوّل طلب بعدها ~دقيقة.
- **القاعدة المجانية محدودة المدّة**، والمدّة **غير مؤكَّدة في هذا
  المستودع** — راجع لوحة Render.
- **كل الجدولة على GitHub Actions**: نقطة فشل واحدة معترف بها.
- **فقدان `FIELD_ENCRYPTION_KEY` لا استعادة منه.**
- **العدّادات «منذ الإقلاع»** وتُصفَّر مع كل نومة.

كلّها في `docs/22-faq.md` بصياغة أطول.
