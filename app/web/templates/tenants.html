🏢 Multi-Tenant Management

Multi-tenant SaaS:
  • كل tenant له tenant_id خاص في كل الجداول.
  • كل tenant له API key خاص (X-API-Key header).
  • عند تفعيل SAAS_MODE=true، الطلبات بدون API key تُرفض (401).
  • في الوضع الافتراضي، tenant_id=1 يُستخدم تلقائياً (متوافق مع النسخة السابقة).
  • تنبيه: SQLite لا يدعم RLS على مستوى قاعدة البيانات؛ العزل يتم على مستوى ORM. للإنتاج متعدد المستأجرين، استخدم PostgreSQL.

➕ إنشاء Tenant جديد

لا يمكن إنشاء tenants من الواجهة لأسباب أمنية. استخدم السكربت:

python scripts/create_tenant.py \
  --name "Acme Corp" \
  --slug acme \
  --plan pro

السكربت سيعرض API key مرة واحدة فقط — احفظه في مكان آمن.

🔗 كيفية استخدام API key

curl -H "X-API-Key: lip_acme_<your-key>" \
     https://your-host/api/v1/links

أو في JavaScript:

fetch('/api/v1/stats', {
  headers: { 'X-API-Key': 'lip_acme_...' }
})
